# Полномочия агента в полном контуре

Пробы на стенде с фиктивными секретами: orbit server и session во вложенном Docker, два runner, worker, поддельный Messages API. Протокол 17, Claude Code с фиктивными учётными данными.

| Направление | Факт | Решение |
|---|---|---|
| Контейнер session, права | `CapEff=0`, `NoNewPrivs=1`, seccomp; `/run/secrets` и `/work` (0700 root) не читаются; `/proc/1/environ` процесса root читается, `/proc/1/fd` закрыт; сокета Docker нет, `mount` отказывает | принято |
| Контейнер session, сеть | открыты `:2201`, `:2202`, поддельный API; `2200` закрыт (по имени, адресам server в обеих сетях и через шлюз — проба в `docker/e2e.sh`); внешний интернет закрыт сетью стенда (`internal: true`), на настоящем хосте не проверено | 2200 — только на адресе сети узлов |
| Образ session | нет `perl`, `python3`, `git`, `curl`, `wget`, `ssh`, `nc`, `rg` (проверка в `docker/e2e.sh`) | файлы `perl` удалены из `perl-base` |
| Учётные данные агента | `~/.claude/.credentials.json` (0600) принадлежит агенту и читается им | граница доверия: учётные данные нужны процессу агента |
| Хуки и MCP в контейнере | пользовательский хук срабатывает от пользователя агента без секретов; проектный `.mcp.json` в контейнере процессов не запускает (только на runner); `managed-mcp.json` — root, токен MCP читается всеми и в журналах не встречается | принято |
| Команды на runner | идут от пользователя runner; каталог личности (`orbit_key`, ключ узла, сертификат, fingerprint) читается; `orbit_key` совпадает с ключом входа worker; с ним агент регистрирует новый узел (виден в `runner_list`, после остановки — «Offline») и входит на server как worker | граница доверия, принято (контракт, «Авторизация») |
| Окружение runner | секреты слоя окружения видны в `env` | цель Iapetus: окружение runner — окружение агента |
| Маскирование вывода | известные секреты в выводе Bash заменяются `***`; обходится `base64`, `cut`, `rev`, `fold`, `tr`; секрет из `.env` проекта через встроенный Read уходит целиком; переменная без признака секрета в имени не маскируется | ограничение: защищает от случайной утечки, не от намеренной |
| `runner_clone` | принимает `$HOME` runner; клон отдаёт агенту весь домашний каталог, включая каталог личности | граница доверия, принято |
| Журналы (DEBUG) | фиктивные секреты, `orbit_key`, токен MCP в журналах server, runner, session, dind, worker не найдены; в журнале поддельного API — только то, что пробы вывели сами | принято |
| Потеря session | после `docker kill` session процессы команд (группа, `nohup`, `setsid`, двойной fork) живут и через 60 с; runner повторяет подключение с растущей паузой; контейнер остаётся `Exited (137)` | runner завершает процессы через 5 минут (план) |

Не снято: запуск `.mcp.json` в контейнере без `managed-mcp.json`, управляемые хуки (`managed-on`), содержимое снимка окружения, который получает узел-двойник, выход в интернет на настоящем хосте.
